Derived Russian stair and slab translations for Rechiseled 1.2.6.
The generator uses the installed mod English language file and source/rtf-19/rechiseled.json from this repository.
Run derive_rechiseled_ru.py in the VOLTAGE workspace layout; the resulting JSON is distributed under GNU AGPL version 3.
Original RTF Extension: https://github.com/Kamas50/RTF_Extension
